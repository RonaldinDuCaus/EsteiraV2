# Uso do site

## Dashboard

Apresenta o último item, quantidade de componentes ativos, eventos do dia, itens desconhecidos e estado dos dispositivos.

## Cadastro

Informe nome, categoria e código ou valor. Envie entre uma e dez imagens. Para o reconhecimento futuro, use fotografias com iluminação e distância semelhantes às da esteira.

## Componentes

Exibe as referências já cadastradas. Um componente pode ser desativado sem apagar seu histórico.

## Histórico

Lista capturas, resultados, confiança, status e data. Eventos enviados pela ESP32-CAM aparecem automaticamente após atualização dos dados.
